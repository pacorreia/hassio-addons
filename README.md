# Home Assistant Add-ons

This repository contains custom add-ons for [Home Assistant](https://www.home-assistant.io/).

## Installation

1. Open **Settings → Add-ons → Add-on store** in Home Assistant.
2. Select the three-dot menu and choose **Repositories**.
3. Add this repository URL:

	```text
	https://github.com/pacorreia/hassio-addons
	```

4. Choose an add-on, then select **Install**.

Follow each add-on's documentation for configuration and usage details.

## Support

Before opening an issue, check the add-on logs and confirm that Home Assistant and the add-on are up to date. When reporting a problem, include the add-on version, Home Assistant version, architecture, relevant configuration, and logs.
